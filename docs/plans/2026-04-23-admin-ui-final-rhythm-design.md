# 管理后台最终节奏压缩与质感统一设计

## 1. 背景

当前后台已经完成两轮核心改造：

1. 从旧的“大横幅式后台”重构为更接近 `shadcn-admin` 的工作台结构
2. 将整体视觉从蓝色品牌风格压缩为更中性的冷灰工作台风格

但和参考项目相比，当前界面仍然存在最后一层“节奏偏松、组件偏厚”的问题：

- Sidebar 的品牌区仍比参考站更像“品牌卡片”而非“导航头”
- Topbar 仍略有页面横幅感
- Summary cards 仍然比参考站更像独立卡片，而不是安静的数据摘要块
- Table / Tabs / Form controls 在字重、行高、边框和互动细节上仍保留一点 Ant Design 的默认厚重感

用户要求本轮做最后一次纯视觉收口，并明确指定：

- 继续压 `sidebar / topbar / summary cards`
- 继续压 `table / tabs / form controls`
- 做到更像参考站的整体节奏
- 这是最后一轮质感统一，而不是再新增新模块

## 2. 目标

### 2.1 目标

- 让 shell 更像 `shadcn-admin` 的薄工作台，而不是后台模板壳
- 压缩 Sidebar、Topbar、SummaryCard 的留白与视觉重量
- 压缩 Table、Tabs、Form controls 的厚度、字重与边框存在感
- 让列表页、详情页、整改页共享更一致的视觉节奏

### 2.2 非目标

- 不改动业务流程
- 不新增路由
- 不更换组件库
- 不做新的信息架构重构
- 不继续大改页面结构，只做节奏与组件层面的最后收口

## 3. 核心方向

### 3.1 Sidebar

目标是从“有品牌展示感的左侧区域”进一步压成“导航头 + 导航列表”。

本轮调整方向：

- 品牌区高度继续降低
- `AS` badge 缩小、变薄、去中心化
- 品牌文案压成单组信息，不再像两级品牌展示
- 导航项高度再下降一点
- active 态继续做浅灰片状表达，不做视觉突起
- icon 继续弱化，让阅读中心回到文字本身

### 3.2 Topbar

目标是让 topbar 更像工作区头，而不是页面头图。

本轮调整方向：

- 外层容器继续变薄
- padding 再收紧
- 标题字号与字重再略压一档
- breadcrumb 更细、更轻
- 描述文字更淡、更短、更像辅助说明
- 控制其视觉角色为“导航与定位”，而不是“展示与说明”

### 3.3 Summary cards

目标是让它们从“强调型统计卡片”转向“静态摘要块”。

本轮调整方向：

- 卡片高度进一步降低
- 数值字号略收
- label/helper 的占比更轻
- 卡片边框与阴影再减弱
- 四张卡片在观感上接近参考站的 summary strip，而不是四块单独强调模块

## 4. 组件细化方向

### 4.1 Table

本轮重点不在功能，而在节奏：

- 表头字重继续压轻，但保持清晰
- 表头字号更接近小写工具型表格
- 表格行上下 padding 再收一层
- hover 只保留极浅灰反馈
- 操作列按钮做成更低存在感的文本动作
- 分页 active 状态也继续收成浅灰底 + 深字

目标是从“Ant 表格”变成“工作台 data table”。

### 4.2 Tabs

- tab label 的字号、字重再压一层
- active tab 只靠深色文字 + 细 ink bar 表达
- tab hover 不再明显高亮
- tab 内容顶部的节奏继续压紧

目标是让 tabs 像安静的内容切换器，而不是视觉强控件。

### 4.3 Form controls

- 输入框、Select、日期控件高度统一为更薄的工作台节奏
- 边框颜色更接近参考站的细灰线
- focus ring 再收轻，保留可用性但不抢视觉
- placeholder 更浅
- 正文字重更稳定
- 主按钮 / 次按钮 / 文字按钮的层级更像 shadcn-admin 默认后台

## 5. 页面影响

本轮虽然以样式为主，但影响会覆盖主要后台页面：

- `关键词规则`
- `检测任务`
- `风险结果`
- `操作日志`
- `文稿详情`
- `任务详情`
- `内容整改`

尤其是以下三类区域会直接受益：

1. 列表页顶部工具栏
2. 列表页数据表格与分页
3. 详情页 tabs / side cards / snapshot 区域

## 6. 技术策略

- 优先通过 `theme.css` 和 `layout.css` 完成最后一轮视觉节奏统一
- 仅在确有必要时微调 sidebar 品牌区的 JSX 结构，压缩为更像参考站的导航头
- 用 CSS regression tests 锁定：
  - 不再回到蓝色强调
  - shell / summary / table / tabs / form controls 的目标样式存在
- 保持现有业务测试继续通过，避免视觉收口误伤路由、跳转和详情页结构

## 7. 验收标准

### 7.1 Sidebar / Topbar / Summary cards

- 左侧品牌区进一步压缩，接近参考站导航头节奏
- topbar 不再有轻微横幅感
- summary cards 更像安静摘要块，而非强调卡片

### 7.2 Table / Tabs / Form controls

- 表格字重、行高、边框与 hover 更克制
- tabs 更薄、更轻、更安静
- 输入框、下拉、按钮的厚度与边框统一
- 页面之间不再出现“某些控件还像 Ant 默认态”的割裂感

### 7.3 整体观感

- 后台整体更像参考站
- 更薄、更紧、更冷静
- 中文界面依然保留可读性，不为了极限压缩而牺牲扫描效率

## 8. 结论

本轮是一次“最终节奏收口”：

- 不是换新风格
- 不是新增功能
- 而是把当前已完成的后台进一步压到更像 `shadcn-admin` 参考站的工作台质感

重点是：

- 壳层更薄
- 卡片更安静
- 表格更轻
- 控件更统一
