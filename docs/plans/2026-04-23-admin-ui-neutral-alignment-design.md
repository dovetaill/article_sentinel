# 管理后台冷灰中性风格对齐设计

## 1. 背景

当前后台已经完成路由重构、文稿详情页、任务详情页与整体壳层简化，但视觉气质仍然保留了偏强的蓝色品牌感、较重的渐变和偏软的大圆角。这与用户要求的 `shadcn-admin` 默认工作台风格仍有明显差距。

用户本轮要求非常明确：

- 更偏 `shadcn-admin` 默认风格
- 不要蓝色主强调
- 更冷灰、更中性、更安静
- 继续压缩顶部、卡片与表格的视觉噪音
- 让页面更像统一的工作台，而不是带品牌气质的后台模板

## 2. 本轮目标

### 2.1 目标

- 去掉当前后台中的蓝色主强调、蓝色渐变与蓝色激活感
- 将整体视觉改为冷灰、弱品牌色、低对比强调的工作台风格
- 统一页面壳层、卡片、表格、筛选条、按钮、详情页的中性风格
- 让 `关键词规则`、`检测任务`、`风险结果`、`操作日志`、`文稿详情`、`任务详情` 在同一视觉系统下工作

### 2.2 非目标

- 不改动现有路由结构与业务流程
- 不新增一级导航
- 不更换组件库
- 不引入新的后端接口

## 3. 视觉方向

### 3.1 色彩

采用接近 `shadcn-admin` 默认后台的冷灰中性色体系：

- 页面背景：浅灰白
- 卡片背景：纯白或接近纯白
- 边框：浅灰细线
- 主文字：近黑深灰
- 次级文字：中灰
- 主按钮：炭灰 / 近黑，而不是蓝色
- hover / active：浅灰底，不使用明显蓝色
- 保留红色给风险或危险操作，但饱和度略低，避免刺眼

### 3.2 层次

减少“靠颜色制造层次”，改为：

- 更克制的边框
- 更轻的阴影
- 更紧的留白
- 更稳定的对齐关系

页面应呈现：

- 安静
- 冷静
- 可扫描
- 工具化

### 3.3 圆角与阴影

- 将现有偏大的圆角进一步收紧
- 卡片、输入框、按钮的圆角统一
- 阴影改为非常轻，主要依靠边框区分层级
- 去掉显著的玻璃感、品牌化渐变和泛光感

## 4. 壳层设计

### 4.1 左侧导航

- 保留品牌标识与主导航，但弱化品牌展示感
- active item 改为浅灰背景 + 深色文字，不再使用蓝色高亮
- 图标框不再呈现偏蓝视觉中心，而是作为中性辅助元素

### 4.2 顶部区域

- 顶部容器进一步压缩高度
- 标题与说明的层级更像面包屑下的工作区标题
- 标题字号再略收一档，减少“页面横幅感”
- 描述文本更轻、更短、更像辅助说明

## 5. 页面与组件策略

### 5.1 卡片与 SummaryCard

- summary cards 不再高强调，而是成为平静的信息块
- 数字仍清晰，但不通过颜色或阴影制造强存在感
- helper text 更弱、更紧

### 5.2 表格

目标是更接近 `shadcn-admin` 风格的数据表：

- 表头更轻、更规整
- 行高与上下 padding 再收一层
- hover 仅做极轻浅灰反馈
- 操作列链接变成更克制的 text action
- 减少 Ant Design 默认后台感

### 5.3 筛选条

- 更像顶部工具栏，而不是一排表单
- 输入框与下拉的高度、边框、圆角统一
- 查询 / 重置按钮采用统一冷灰按钮体系
- 元信息提示文案继续弱化

### 5.4 详情页

`文稿详情` 与 `任务详情` 继续一起收敛：

- 摘要区更轻
- 左右栏都使用统一白卡片 + 浅边框
- tabs、描述列表、代码快照区都纳入同一灰度系统
- 详情页保留结构，但进一步消除色彩噪音

## 6. 技术策略

本轮以样式系统调整为主，少量页面结构配合：

- 优先修改 `theme.css` 中的设计 token
- 再修改 `layout.css` 中的 shell、card、toolbar、table、detail-page 样式
- 仅在必要时微调页面组件结构，以更好承载中性风格
- 继续通过测试锁定关键 UI 行为，避免任务详情、文稿详情和跳转关系退化

## 8. 验收标准

### 8.1 视觉验收

- 页面中不再存在明显蓝色主强调
- 主按钮不再使用蓝色系统
- 左侧导航 active、顶部、卡片、表格、筛选条整体接近 `shadcn-admin` 默认中性工作台风格
- 整体更冷灰、更克制、更像工具界面

### 8.2 交互验收

- 现有路由与跳转关系保持不变
- 文稿详情、任务详情仍是完整独立详情页
- 列表页筛选与操作行为不退化

### 8.3 技术验收

- 测试通过
- 构建通过
- 保持与现有业务接口兼容

## 9. 结论

本轮不是继续做“新设计”，而是把已经成型的后台进一步压向 `shadcn-admin` 的默认中性工作台审美：

- 去蓝
- 去品牌感
- 去夸张层次
- 用冷灰、留白、边框和密度统一整个后台
