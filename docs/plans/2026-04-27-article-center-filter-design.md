# 文稿中心筛选修正设计

**目标**
- 文稿中心仅保留“标题模糊查询”和“文稿 ID 精确查询”两个筛选条件。
- `/tasks/:taskId/results` 结果列表补充文稿 ID 列，且文稿 ID 展示不带 `#` 前缀。
- `/results` 总结果页结果列表同步补充文稿 ID 列，且文稿 ID 展示不带 `#` 前缀。

**方案**
- 前端文稿中心页拆分现有单一搜索框为两个输入框：`title` 与 `article_id`。
- 前端文章列表服务改为向 `/api/v1/article-inspect/articles` 传 `title`、`article_id`，不再传通用 `query/keyword`。
- 后端文章列表接口改为显式解析 `title`、`article_id`，仓储查询只做标题 `LIKE` 和文章 ID 精确匹配。
- 任务结果页与总结果页新增 `文稿ID` 列；文稿中心现有 `文章编号` 列去掉 `#` 前缀。

**验证**
- 更新 Go 接口测试覆盖 `title` 和 `article_id` 查询。
- 更新前端单测覆盖两个筛选项、请求参数、以及两个结果列表中 ID 不带 `#` 的展示。
